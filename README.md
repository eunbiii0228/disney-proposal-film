# 디즈니 프로포즈 영상 기획안

노남규 · 김가영 두 사람의 실화를 밝고 사랑스러운 디즈니 단편 애니메이션으로 옮기는
프로포즈 영상 프로젝트의 기획 산출물입니다.

다섯 살에 아버지 앞에 무릎 꿇고 한 첫 번째 약속이, 스물 몇 해 뒤 같은 자세의
두 번째 약속으로 이어지는 구성입니다.

## 기획안 구성

1. **나레이션 대본** — 8씬 · 육성 낭독(🎙)과 화면 자막(📝) 구분 · 씬별 녹음 지시 포함
2. **스토리보드 16분할** — 컷별 길이 · 카메라 · 후반 합성 요소
3. **캐릭터 시트** — 턴어라운드 2종 + 키 차이 기준표 + 컷별 의상표

## 제작 원칙

- **어두운 컷을 만들지 않는다.** 밤 장면도 앰버 조명으로 포근하게 간다.
- **마법 요소는 세 가지만** — 빛가루 · 꽃잎 · 별. C02 · C07 · C16 세 컷에만 크게 쓴다.
- **웃음이 먼저, 감동은 그다음.** 웃음 포인트 7개를 배치하고 마지막 16초에만 속도를 늦춘다.
- **C02와 C15는 완전히 같은 구도.** 다섯 살의 무릎과 지금의 무릎이 겹치는 순간이 결론이다.
- **키 비율은 기준표를 따른다.** 여자 정수리 = 남자 눈썹 높이(약 12cm 차).

## 제작 순서

1. 시작 프레임 16장 — 캐릭터 시트를 고정 레퍼런스로 생성, 얼굴 검수
2. 16컷 애니메이트 — Kling 3.0 무음
3. 후반 합성 — 빛 리본, 점선 경로, 꽃잎, 하트 폭죽, 별자리, 먹구름, 자막
4. 나레이션 녹음
5. 음악 · 믹스

## PDF 다시 만들기

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --remote-debugging-port=9333 --remote-allow-origins='*' \
  --user-data-dir=/tmp/chromeprof about:blank
# 이후 CDP Page.printToPDF 를 displayHeaderFooter:false, preferCSSPageSize:true 로 호출
```

> Chrome CLI 의 `--print-to-pdf` 는 머리말·꼬리말에 파일 경로가 박히므로
> 고객 배포본에는 쓰지 않는다.
